# Catalys sample sales dashboard

An interactive sales analytics dashboard for Catalys, built on synthetic CRM data as a sample
for my application as Sales Analyst (working student).

All data in this project is synthetic and generated by a script. It does not reflect Catalys'
real figures. This project is not affiliated with or endorsed by Catalys.

## Structure
- `generator/`: Python script that creates the synthetic CRM data. All assumptions live in
  `generator/config.py`. Run `python3 generator/generate.py` (standard library only) to
  rebuild `site/data/data.json`. `python3 generator/check_seeds.py` shows how often each
  modelled pattern appears across random seeds
- `site/`: static dashboard page, served via GitHub Pages
